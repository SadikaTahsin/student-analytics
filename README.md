# 🎓 Student Score Prediction Project

## 📌 About
This project predicts student final scores using Machine Learning.

## 🚀 Features
- Data cleaning and analysis
- Random Forest ML model
- Score prediction dashboard using Streamlit

## 🛠 Tools Used
Python  
Pandas  
Scikit-learn  
Streamlit  

## ▶️ How to Run
1. Install libraries
pip install pandas scikit-learn streamlit joblib

2. Run dashboard
streamlit run app.py

## 📊 Result
The model predicts student performance based on study hours, attendance, and previous scores.
